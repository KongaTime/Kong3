# RPCS3 for PS5 v0.1.0-beta.1

RPCS3, the PlayStation 3 emulator, as a homebrew title for the PS5 (`PPSA99200`):
the first beta, as source.

> [!IMPORTANT]
> **Piracy is not condoned.** This release contains no games, no BIOS files, no
> console firmware and no decryption keys, and none will ever be provided or linked
> to. Use only **legally obtained backups of games you own**, made yourself from your
> own discs or digital purchases, and the PS3 system software from Sony's own
> `PS3UPDAT.PUP`. Please don't ask for, or post links to, games, firmware or keys in
> issues or discussions: they will be removed.

> [!WARNING]
> **This is a source release. There is no download of the built title, and there will
> not be one.** RPCS3 is GPL-2.0-only, and the PS5 platform layer every title links is
> GPL-3.0-or-later: the two cannot be combined into one program that is shared. Build
> it for your own console from the source below, and **please don't share the builds**
> (`eboot.bin`, `rpcs3-code.bin` or the title folder).

## Highlights

- **PS3 games play on the PS5.** Both of RPCS3's recompilers run on the console
  (LLVM 22, built for it), with RADV, Mesa's Vulkan driver, ported to the PS5.
- **Long sessions no longer run out of memory.** Each graphics program kept about
  900 KiB of descriptor pools; in an open-world game the heap grew to 8.6 GiB and the
  title died after about 20 minutes. They are now about 18 KiB each: the same game
  played 20 minutes with the heap flat at about 3 GiB.
- **Frame generation**, three ways: the title's own, Lossless Scaling's (from your
  own `Lossless.dll`) and MihawkGen's neural network, built in.
- **A launcher made for the console**: games from folders and ISOs, trophies, save
  data, save states, game patches, package installs, per-game settings and
  controller remapping, screenshots, a pause menu with quick settings and a
  performance page.

## Tested for this release

On my console, with the build of this source (build 150):

| What | Result |
| --- | --- |
| An open-world game I test with | 20 minutes, through its first missions to a save; about 27 fps, about 45 shown with frame generation; heap flat at about 3 GiB; no crash |
| Another open-world game | 7.5 minutes; about 25 fps; graphics thread flat at about 600 MiB (it held over 2 GiB before the fix); no crash |
| An action game that turns on the controller's motion sensors | its triggers did nothing before (the controller reported no motion sensors, so the game refused it); now the game gets sensor mode and the triggers' pressure, and its trigger moves work; about 35 fps for 3 minutes (with build 151: this source's emulator, and the start-up of the next phase) |
| First boot after a fresh install | the PS3 system software installs from `PS3UPDAT.PUP`; games compile their code on first boot (minutes), then load from the cache |

Not tested in this release: most of the PS3 library; the driver's memory fix (not
made yet).

## Known issues

- Heavy games run well below full speed: the emulated SPUs are the limit on the
  console's CPU. Frame generation smooths motion; it does not speed the game up.
- Fast camera turns with frame generation can smear or double edges.
- A game's first boot compiles for minutes with little on screen; new areas stutter
  while their shaders compile the first time.
- Some games freeze unless **Accurate SPU Reservations** is on (the default).
- The graphics driver keeps up to 1 MiB for each of RPCS3's command buffers (about
  500 MiB in a long session); the heap creeps up slowly in long sessions.
- One open-world game shows triangular texture glitches at times, with frame
  generation on or off (carried over, not re-checked).

## Build and install

Everything is in [`rpcs3/README.md`](https://github.com/KongaTime/PS5_RPCS3Title/blob/v0.1.0-beta.1/rpcs3/README.md):
a Linux PC, five repositories side by side, `ps5/tools/bootstrap.sh`, then
`rpcs3/build-rpcs3.sh rpcs3_ps5 Fusion` and `ps5/tools/build.sh`. The first build
takes hours (LLVM). Copy `dist/PPSA99200/` to `/data/homebrew/PPSA99200/`, add
Sony's `PS3UPDAT.PUP` and your own game backups in `rpcs3/games/`.

## Reporting problems

Send `rpcs3/cache/RPCS3.log` and `rpcs3-trace.txt` from the title's folder, copied
before you launch again, and say what you saw and when. Never attach games,
firmware, keys or saves.
