# Kong³ v1.0.0-beta1: source

The complete source of [Kong³ v1.0.0-beta1](https://github.com/KongaTime/Kong3/releases/tag/v1.0.0-beta1),
as its licence asks: one archive for each part in the title, at the revision it was
built from. Nothing here is needed to play: the title itself is the ZIP on that release.

- `SOURCES.txt`: each archive, the part it holds and where that part comes from.
- `SHA256SUMS`: the digests of these archives and of the title's ZIP.

The parts: the title, RPCS3 (my fork, PS5_RPCS3), RADV (PS5_Mesa) and the payload SDK
it was built against, the libraries RPCS3 bundles that are in the title (LLVM,
Abseil, Protocol Buffers, curl, OpenAL Soft and the rest), FFmpeg and GNU libiconv.
Every part's licence is in the title's `licenses/` folder.
