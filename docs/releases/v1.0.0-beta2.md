# Kong³ v1.0.0-beta2

RPCS3, the PlayStation 3 emulator, as a homebrew title for the PS5 (`PPSA99200`):
smoother, a little faster, and a clear message when a game can't start.

> [!IMPORTANT]
> **Piracy is not condoned.** This release contains no games, no BIOS files, no
> console firmware and no decryption keys, and none will ever be provided or linked
> to. Use only **legally obtained backups of games you own**, made yourself from your
> own discs or digital purchases, and the PS3 system software from Sony's own
> `PS3UPDAT.PUP`. Please don't ask for, or post links to, games, firmware or keys in
> issues or discussions: they will be removed.

> [!NOTE]
> As a whole the title is GPL-2.0-only, RPCS3's licence, and nothing in it is
> GPL-3.0-or-later. Its complete source is in
> [v1.0.0-beta2: source](https://github.com/KongaTime/Kong3/releases/tag/v1.0.0-beta2-source),
> and `licenses/README.txt` in the title lists every part, its licence and its source.

## What's new

- **No more logging stutter.** Writing the log could hold the whole emulator for
  seconds at a time; the log now goes through a queue and never waits. Army of Two:
  The 40th Day's title screen no longer stutters.
- **Faster SPUs.** A common SPU store pattern now compiles without a trip through
  memory: GTA IV's busy streets went from 22.6 to 24.0 fps, and the busiest audio SPU
  from 98% to about 85% busy. Other SPU-heavy games gain too.
- **Shader interpreter, if you want it.** Shader Mode offers *Async Recompiler with
  Shader Interpreter*: fewer shader-compile hitches, at the cost of a long first
  set-up. Off by default.
- **A game that can't start says why.** It used to drop to the PS5 home screen (for
  example, without the PS3 system software installed). Now the launcher stays and
  shows **Couldn't start the game** with what to do.
- **`PS3UPDAT.PUP` is found under any capitalisation**, and also as `PS3UPDAT.PUP.PUP`
  (Windows hiding the extension) or inside `rpcs3/`. If none is found, the trace lists
  what is in the folder, so a misplaced file shows in the log.
- **RPCS3 brought up to date** with upstream (SPU, RSX, PPU and loader fixes).
- **Better logs for reports:** what each thread waits on, and what a stalled RSX
  semaphore waited for.

## Known issues

- **SPU Block Size Mega or Giga can freeze some games**: GTA V on Mega (also in its
  prologue), God of War: Ascension on Giga. Keep **Safe** for those. Being looked at.
- The first boot of each game after updating rebuilds its SPU cache (a few minutes).
- Army of Two: The 40th Day pauses for about 13 seconds after pressing Start once.
- Heavy games run well below full speed: the emulated SPUs are the limit on the
  console's CPU. Frame generation smooths motion; it does not speed the game up.
- A game's first boot compiles for minutes with little on screen; new areas stutter
  while their shaders compile the first time.
- Some games freeze unless **Accurate SPU Reservations** is on (the default).

## Install

1. Unpack the ZIP and copy `PPSA99200/` to the console's `/data/homebrew/PPSA99200/`
   over FTP, then register it with ShadowMountPlus.
2. Put Sony's `PS3UPDAT.PUP` in `/data/homebrew/PPSA99200/` (next to `eboot.bin`)
   and launch the title: it installs the PS3 system software once.
3. Put your own game backups in `/data/homebrew/PPSA99200/rpcs3/games/`.

Updating from beta1: copy the new folder over the old one; your settings, saves,
games and caches stay. Building it yourself:
[`rpcs3/README.md`](https://github.com/KongaTime/Kong3/blob/v1.0.0-beta2/rpcs3/README.md).

## Reporting problems

Send `rpcs3/cache/RPCS3.log` and `rpcs3-trace.txt` from the title's folder, copied
before you launch again, and say what you saw and when. Never attach games,
firmware, keys or saves.
